# Changelog

## 0.1.0

### Features

- Four skills: `uiprobe:match-design` brings a page in line with its Figma design, `uiprobe:design-qa-summary` summarises a probe's findings to share, `uiprobe:triage-findings` goes through findings with you and dismisses the intentional ones, and `uiprobe:pr-design-check` checks a pull request's pages against Figma and writes a note for the pull request.
